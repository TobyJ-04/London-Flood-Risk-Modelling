The raw datasets used in this project are not included in the repository due to file size and source-data distribution considerations.

The project uses data from:

- Ordnance Survey OpenMap Local – building footprints
- Ordnance Survey Open UPRN – property identifiers
- Domestic Energy Performance Certificates – domestic property information
- Environment Agency – flood-depth datasets
- Multi-Coloured Manual – depth-damage relationships
- Office for National Statistics – Consumer Prices Index
- London borough boundaries

The accompanying project report and scripts document how these datasets were processed and integrated within the modelling workflow.
