This project tackles UK natural hazard modelling at a granular scale, looking at building-level flood risk and financial loss modelling in London. The project demonstrates a number of tasks and technical skills relevant to catastrophe risk modelling and exposure management. The workflow incorporates the hazard, exposure, vulnerability and financial loss estimation components. However, the project represents a simplified deterministic flood-risk modelling framework rather than a full probabilistic catastrophe model. The core database for the model was constructed in SQL, which was linked to both R and QGIS to create various figures and maps, including an illustrative exceedance probability (EP) curve and associated average annual loss (AAL) calculation.
